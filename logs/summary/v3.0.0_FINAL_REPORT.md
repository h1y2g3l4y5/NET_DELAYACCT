## 七、关键设计决策

1. **TCP TX 语义**: 从"sendmsg 到 driver"改为"clone 创建到 driver"。理由：原始 skb 留在队列中，实际传输的是 clone；clone 块的 tx_start 重置使首次发送和重传统一度量。

2. **UDP rx_end 位置**: 从"checksum 验证前"移至"copy+checksum 成功后"。理由：`skb_copy_and_csum_datagram_msg` 将 checksum 验证和 copy 合并进行，无法实现"校验后、拷贝前"的语义。

3. **MSG_PEEK 守卫**: 在所有 recvmsg 路径添加 `!peeking` 或 `!MSG_PEEK` 守卫。理由：peek 不消耗数据，不应消耗时间戳，否则后续真正 recv 时 start 为 0 导致不计数。

4. **PS copy 重传路径**: 在 `__pskb_copy` 创建 nskb 后单独添加 tx_start。理由：clone_it=0 不进入 clone 块重置时间戳，需独立设置。

5. **死代码清理 (NEW-BUG-8)**: 直接删除 tcp_sendmsg_locked 中的 tx_start。理由：clone 块会覆盖该时间戳，保留只会造成维护者误解。
